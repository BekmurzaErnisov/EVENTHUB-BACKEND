# EventHub — Backend API

Серверная часть платформы EventHub, отвечающая за бизнес-логику, управление мероприятиями, аутентификацию пользователей, регистрацию на события и обработку медиафайлов.

---

## 🏗 Технологический стек

- **Framework:** NestJS (Node.js)
- **Database & ORM:** PostgreSQL, TypeORM
- **Authentication:** JWT (JSON Web Tokens) + Guards
- **File Uploads:** Multer (для загрузки изображений обложек)

---

## 🚀 Инструкция по запуску

### 1. Установка зависимостей
```bash
npm install

2. Настройка переменных окружения
Создайте файл .env в корневой директории бэкенда на основе примера (.env.example) и заполните следующие параметры:

PORT=3000
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=ваш_пароль_бд
DB_NAME=eventhub
JWT_SECRET=ваш_секретный_ключ_jwt

3. Запуск сервера
Bash
# Режим разработки с горячей перезагрузкой (Watch mode)
npm run start:dev

# Продакшн сборка и запуск
npm run build
npm run start:prod

API будет доступно по адресу: http://localhost:3000

🛡 Особенности архитектуры и Edge Cases
Порядок роутинга в контроллерах:

Статические маршруты (например, /events/my, /events/create) строго регистрируются в контроллерах до динамических параметров с UUID (/events/:id), исключая конфликты маршрутизации.

Контроль прав доступа (Ownership Validation):

Эндпоинты обновления (PATCH) и удаления (DELETE) проверяют владельца мероприятия (organizerId). При попытке изменения чужого события выбрасывается ForbiddenException.

Безопасное обновление данных:

Метод update корректно мапит и сохраняет все поля сущности (включая title, description, date, location, price, capacity и ссылки на изображения), предотвращая потерю данных при частичном апдейте.

Валидация и загрузка файлов:

Модуль Multer обрабатывает загрузку изображений с ограничением размера и поддержкой форматов PNG/JPEG.
